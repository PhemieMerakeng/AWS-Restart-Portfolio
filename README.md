# AWS-Restart-Portfolio

### Welcome to my AWS re/Start capstone repository. This project serves as a comprehensive record of my intensive, 3-month journey into cloud computing. It showcases the technical competencies I developed in Linux, Python, Networking, Security, and Core AWS Services.
---

### 📂 Repository Structure
The repository is organized into three primary sections to demonstrate my progression from foundational learning to hands-on implementation:

/Certificates
- Documentation of program completion and industry-standard certifications earned during the course.

/Labs
- Step-by-step documentation and configuration files for AWS-managed labs.
Includes work with VPCs, EC2 instances, S3 bucket policies, and IAM roles.

/Projects
- End-to-end cloud solutions and capstone projects.
Features automated deployments, scripted infrastructure, and multi-tier architecture designs.

During this program, I gained hands-on experience in the following areas:

- Cloud Platforms: AWS (EC2, S3, RDS, VPC, Lambda, IAM, Route 53)
